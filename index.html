    About this dashboard

    Each record in the Willennar Genealogy Center's online catalog (willennar.catalogaccess.com) is copied to the Internet Archive as its own item. "Total" is the number of records in that catalog collection, counted at the last harvest. "Uploaded" is how many of them are now in the eckhartpubliclibrary collection. Each record is counted once, even if it was uploaded more than once.

    "Test" counts trial uploads to archive.org's shared test collection. archive.org removes test items after about 30 days, so this number goes down on its own.

    A total marked * isn't known yet: the catalog count for that collection hasn't been provided.

    This is a snapshot from the most recent update, not a live feed.
